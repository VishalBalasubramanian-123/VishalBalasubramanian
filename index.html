Projects

Bot, a personal executive assistant In progress

For a single Gmail, Calendar and Drive account

Answers questions about your mail, calendar and files by searching a local index that it keeps in sync. When you ask it to send an email or create something, it drafts the action and hands the decision to you before anything goes out.

  • Agent loop on the Anthropic Claude API with typed tool-use schemas
  • Local Gmail, Calendar and Drive ingestion pipeline through Google OAuth
  • Qdrant (local) with hybrid dense and sparse search for retrieval

AI booking and customer service agent In progress

For restaurants and boutique hotels

Answers inbound web chat and completes bookings on its own when it is confident. When a request is ambiguous or high-stakes, it hands the decision to the owner.

  • Agent runtime on AWS AgentCore with the Strands SDK
  • Tool execution on AWS Lambda
  • Supabase with pgvector for business-specific RAG

Built with Python, AWS and Supabase.

Information retrieval engine

University project

A search engine built from scratch. It uses an inverted index with positional postings and ranks results with BM25, a TF-IDF vector space model and a field-weighted baseline. I evaluated all three with P@10 and MRR on the Project Gutenberg corpus.

Built with Python.
